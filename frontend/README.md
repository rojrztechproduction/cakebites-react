# CakeBites React recreation

A responsive React/Vite recreation of the visible CakeBites.pk storefront homepage.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- The public visual banner assets are referenced from the existing CakeBites website URLs, so the design stays visually close to the current site.
- Cart and delivery-area UI are implemented client-side for demo purposes.
- For a production migration, connect products/cart/checkout to your API or commerce backend and copy the assets into `/public/assets`.
